## 🚀 Key Features

### 1. 🌟 Modern Glassmorphism UI & Dark Mode
- Built with a sleek dark slate/midnight background, ambient neon gradient glows, and refined typography using **Plus Jakarta Sans** and **JetBrains Mono**.
- Clean, distraction-free reading experience without legacy clunky ads.

### 2. ⚡ The "Try It Yourself" Live Code Playground
- **Multi-language Sandbox:** Run **HTML5**, **CSS3**, **JavaScript**, **Python**, and **SQL** directly in your browser.
- **Real-Time Execution:** Split-view editor (horizontal or vertical layout switch) with live iframe preview.
- **Python Simulator:** In-browser runtime simulation executing scripts with formatted stdout.
- **Interactive Relational SQL Engine:** Execute `SELECT`, `WHERE`, `ORDER BY`, and `INNER JOIN` against real sample tables (`Customers`, `Orders`, `Products`) with instantaneous tabular output!
- **Developer Ergonomics:** `Ctrl+Enter` shortcut to run code, Reset example, Copy to clipboard, and one-click file download (`.html`, `.py`, `.sql`).

### 3. 📚 Comprehensive Guided Tutorials
- **HTML5:** Fundamentals, tags, attributes, and modern accessible forms.
- **CSS3:** Box model, Flexbox layout, Grid systems, and glassmorphic styling.
- **JavaScript (ES6+):** Modern variables, DOM manipulation, arrow functions, async/await, and APIs.
- **Python:** Syntax, lists, dicts, comprehensions, and functions.
- **SQL:** Querying, filtering, aggregations, and relational joins.
- **Modern Additions:** **React 19** component architecture and **Tailwind CSS v4** utility workflows.
- Sticky chapters sidebar with completion checkmarks, reading time estimations, and embedded "Try It Yourself »" live launch buttons.

### 4. 🎯 Fill-in-the-Blank Code Challenges (Exercises)
- The iconic W3Schools test format modernized: fill in missing syntax keywords inside interactive inputs.
- Instant validation, hint accordion, solution reveal, and celebratory confetti animations!

### 5. 🏆 Interactive Skill Quizzes
- Multiple choice test mode with immediate feedback, explanations for correct answers, and final score percentage calculation.

### 6. 📖 Syntax Reference & Cheat Sheets
- Filterable reference encyclopedia covering HTML tags, CSS properties, JavaScript array/async methods, and SQL commands with instant copy buttons and sandbox previews.

### 7. 🔍 Global Command Palette (`Ctrl + K` / `Cmd + K`)
- Instant fuzzy search across all tutorial chapters, reference items, exercises, and playground shortcuts.

## 🛠️ Quickstart

### Prerequisites
- Node.js (v18+)
- npm

### Run Locally
```bash
cd "c:\Abhay\DevAura"
npm install
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
